ECE661 Team 3 - 完整交付与复现

本包只包含经真实实验支持的正式版本。正式报告按 A/B/C/D 分节，主体最多六页，参考文献另计。四份中文说明分别解释各部分实现、代码、操作、实验和局限。

一、内容与解压
A_Code.zip、B_Code.zip、C_Code.zip、D_Code.zip 都以 ECE661_Project 为公共根目录；按 A→B→C→D 解压到同一个父目录，相同共享源码可以合并。每份都包含完整公共源码，便于独立审阅；模型和对应贴片按职责归档。Shared_Results.zip 是结果、原始逐图记录和复现审计；它也以同一根目录组织。

二、依赖与执行顺序
实际运行环境为 Windows / RTX 5080、Python 3.13.5、PyTorch 2.10.0.dev20251010+cu130、CUDA runtime 13.0。requirements-local-tested.txt 记录所用包；若使用其他环境，先通过 CUDA 梯度和数值检查。正式训练/优化用 float32 张量；cuDNN TF32 设置见环境记录。

1. python -m scripts.local_gpu check
2. python -m scripts.workflow prepare
3. python -m scripts.run_training
4. python -m scripts.local_gpu calibrate
5. python -m scripts.local_gpu attack
6. python -m scripts.local_gpu final
7. python -m scripts.analyze_results
8. python -m scripts.export_visual_assets
9. python -m scripts.publication_figures

A 提供固定划分、三个正式模型和指标；B 提供公共渲染/优化器与 132 份基础贴片；C 复用 B 并新增 231 份集成/时间组贴片；D 复用基础贴片并新增 198 份防御主贴片和 24 份强度贴片。最终测试要在全部候选冻结后进行，不能只解压单个部分便绕过完整冻结检查。

三、复用和重跑
已提供的权重/贴片可以直接重算结果。若要从头重训，使用新的输出目录，避免覆盖冻结权重。已有正式结果时不要无意重标定预算；改变权重、配置或预算后需要重跑受影响条件并建立新冻结清单。CIFAR10_Dataset.zip 提供已校验的官方原始数据归档，解压到同一 ECE661_Project 后可离线 prepare；也可从官方 HTTPS URL 下载。官方 MD5 为 c58f30108f718f92721af3b95e74349a。

四、证据
主矩阵 561 份，强度贴片 24 份；1,626 个每图八次抽样的评价文件和 12 个每图 32 次的文件，共 1,638。每个模型均完成 200 epochs；以验证准确率选权重，测试不参与方法选择。模型 seed 17 与贴片 seeds 101/102/103 分开，三个贴片重复不代表三次模型训练。

五、文稿再生成
图表由 scripts/publication_figures.py 从完整审计结果生成。scripts/write_report.py 写入 NeurIPS 2026 源码，使用 Tectonic/兼容 TeX 编译；源文件与原始样式随包提供。中文说明使用 reportlab，ECE661_CJK_FONT 可指向已安装中文 TrueType 字体。Windows 默认使用 SimHei；不将系统字体文件作为独立资源再分发。

六、海报与展示
ECE661_Poster.pdf 由课程指定三栏模板填入真实图表，保留 Duke 标识，打印尺寸 40×22.5 英寸。展示、打印、现场答辩和同学互评仍须由成员按课程安排完成；文件不声称已代替现场活动。

七、核查与使用范围
SHA256_MANIFEST.json 绑定全部最终文件。results/evaluation_audit.json 与 results/analysis.json 保存审计和分析依据。区间按图片分层 bootstrap，条件于固定模型和贴片；不涵盖模型训练随机性。数字实验不构成认证或物理场景保证。AI 辅助了代码、执行、分析和写作；成员应阅读实现并理解结果，文稿不虚构个人投入。
